{%- comment -%} Static illustrated map of festival venues — single source for both /programma/ and /prenota/. Data comes from _data/luoghi.yml. Each pin is an linking to https://www.google.com/maps?q=lat,lng which opens in the user's default maps app on mobile and in Google Maps on desktop. No embedded JS, no third-party cookies, no tracking. The basemap (streets + buildings) is precomputed from OpenStreetMap via Overpass API and lives in _includes/luoghi-basemap.html. The projection used to bake those paths matches the one below, so pins and streets line up. Pin positions are computed in Liquid using the same projection: lat_top = 45.0420 (north edge, smaller y in SVG) lon_left = 8.3090 (west edge) x_scale = 106054 (= 78.5 km/° × 1351 px/km, lon at 45° lat) y_scale = 149961 (= 111 km/° × 1351 px/km) x_origin = 129 (px offset to centre map content horizontally) y_origin = 80 (px padding above the map content) 100 m on the map = 135 px (drives the scale bar). {%- endcomment -%} {%- assign lat_top = 45.0420 -%} {%- assign lon_left = 8.3090 -%} {%- assign x_scale = 106054 -%} {%- assign y_scale = 149961 -%} {%- assign x_origin = 129 -%} {%- assign y_origin = 80 -%}
